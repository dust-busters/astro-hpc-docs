# ASTRO HPC documentation

How to get onto the group's `astro` machines on the UNIMI INDACO cluster, run jobs politely, keep data in the right place, and set up Python and analysis software.

## Start here

1. [Register on INDACO and log in](login.md)
2. Check which node fits your job in the [Overview](overview.md)
3. Read the rules for [running jobs](running-jobs.md) — always use `nice`
4. Put your data in [`DiscEvol_storage`](storage.md), not your home
